Search without surprises.

Alkaid keeps traversal, matching, and concurrency independent of any editor or Git implementation. You choose the ignore policy; it returns stable, byte-accurate results.

Precise matches

Literal or regular-expression search with byte offsets, ranges, whole-word matching, and multiline support.

Stable concurrency

Parallel workers preserve path and byte-offset order, with progress, limits, cancellation, and cleanup.

Safe traversal

Cycle-safe walking, include and exclude globs, hidden-file controls, and pluggable ignore rules.

Start searching.

Add one gem, point it at a directory, and consume matches as a stream.

Ruby
$ bundle add alkaid

require "alkaid"

Alkaid::Search.new(
  Dir.pwd, pattern: "TODO", workers: 4
).run { |match| puts match.path }
